## 安装

把需要的 `plugins/<插件目录>/` 整个复制进 QQ Agent 项目根目录的 `plugins/` 下,重启应用即可。
每个插件的可调项定义在它自己的 `plugin.json` 的 `configSchema` 里,在控制台里调。
