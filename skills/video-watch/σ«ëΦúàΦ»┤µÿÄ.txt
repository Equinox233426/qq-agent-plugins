========================================================
  video-watch —— 让机器人真的看懂视频和动图
  安装说明（照着做就行，一共 4 步）
========================================================

【这个东西是干什么的】

群里谁发个视频或动图，机器人现在只能看到一句
"这是一段视频，30秒"，画面一概不知。

装上这个之后，它会把视频铺成一张 25 格的联络表，
每格标好帧号，于是机器人能说出
"第 13 格（28秒）出现了标题页"这种话。

--------------------------------------------------------
第 1 步：装 Python（如果已经装过就跳过）
--------------------------------------------------------

  打开 https://www.python.org/downloads/
  下载最新版，安装时**务必勾选** "Add Python to PATH"
  这个勾在最下面，很容易漏。漏了后面会找不到 python。

  验证：按 Win+R，输入 cmd 回车，然后敲：
      python --version
  能显示 "Python 3.x.x" 就算好了。

--------------------------------------------------------
第 2 步：装 ffmpeg 和 ImageMagick
--------------------------------------------------------

  按 Win+X，选"终端(管理员)"或"Windows PowerShell(管理员)"，
  然后把下面两行**分别**粘进去回车（一行一行来）：

      winget install Gyan.FFmpeg

      winget install ImageMagick.ImageMagick

  装完后**关掉这个窗口重新开一个**，否则找不到新装的程序。

  验证：
      ffmpeg -version
      magick -version
  两条都能显示版本号就算好了。

  ※ 必须装 ffmpeg 的**完整版**（Gyan.FFmpeg 就是完整版）。
    某些精简版没有 drawtext 滤镜，网格上就不会有帧号。

--------------------------------------------------------
第 3 步：装一个 Python 小库（动图才需要）
--------------------------------------------------------

      pip install pillow

  如果下载很慢或者报错，用国内镜像：

      pip install pillow -i https://pypi.tuna.tsinghua.edu.cn/simple

  ※ 这个只有"动图(GIF)"才用得上。不看动图可以不装。

--------------------------------------------------------
第 4 步：把技能文件夹放进去
--------------------------------------------------------

  1. 找到你的 QQ Agent 安装目录。一般是：
         C:\Users\你的用户名\AppData\Local\Programs\QQ Agent

     找不到的话：右键桌面上的 QQ Agent 图标 → 属性 →
     点"打开文件所在位置"。

  2. 进去后依次打开：  resources  →  app  →  skills

  3. 把压缩包里整个 **video-watch** 文件夹
     （不是里面的文件，是整个文件夹）复制到 skills 里面。

     复制完之后长这样：
         ...\QQ Agent\resources\app\skills\video-watch\index.js
         ...\QQ Agent\resources\app\skills\video-watch\skill.json
         ...\QQ Agent\resources\app\skills\video-watch\README.md
         ...\QQ Agent\resources\app\skills\video-watch\vendor\vw.py

     ※ 注意 vendor 这个子文件夹一定要一起复制过去，
       里面是真正干活的脚本，少了它技能等于空壳。

  4. 重启 QQ Agent。

--------------------------------------------------------
第 5 步：确认装好了
--------------------------------------------------------

  重启后，在 QQ 里对机器人说：

      检查一下视频功能

  机器人会自己跑一遍体检，逐项告诉你 Python / ffmpeg /
  magick / vw.py / Pillow 哪个缺了、怎么装。

  不想麻烦机器人也行，手动开个窗口自己敲三条命令：

      python --version
      ffmpeg -version
      magick -version

  三条都能显示版本号，就说明主链路的依赖齐了。

--------------------------------------------------------
接下来怎么用
--------------------------------------------------------

  不用做任何事。有人发视频或动图，机器人自己就会看。

  想让它专门讲讲某个视频，可以@它说：
      "看看这个视频讲了啥"
      "这段第 20 秒左右是什么"

--------------------------------------------------------
出问题了怎么办
--------------------------------------------------------

  症状：机器人说"抽帧不可用"
  原因：ffmpeg 没装好，或者装的是精简版
  解决：重新跑一遍上面的第 2 步，然后重启 QQ Agent

  症状：机器人说"没找到 vw.py"
  原因：vendor 文件夹没复制过去
  解决：检查 skills\video-watch\vendor\vw.py 存不存在

  症状：动图看不了
  原因：没装 Pillow
  解决：pip install pillow

  症状：网格图上没有帧号
  原因：ffmpeg 精简版缺 drawtext 滤镜，或系统缺字体
  解决：装 Gyan.FFmpeg 完整版

  症状：机器人收了视频但一帧都不给
  原因：设置里的「视频输入专用模型」被填了东西，
        导致系统以为你的模型能直接吃视频，于是发视频本体
        结果被网关过滤
  解决：进设置，把「视频输入专用模型」这一栏**清空**，
        「视频模式」选「抽帧」或「自动」

--------------------------------------------------------
它会占多少磁盘
--------------------------------------------------------

  正常使用几乎不占。技能自己管着：
  · 每次处理完立刻删临时文件
  · 总量超过 300MB 自动清理最旧的
  · 崩溃留下的残留超过 1 小时自动删

  你不用手动清理。
