# 本地绘图 (ComfyUI)

让 QQ 里的机器人用**你自己电脑上的 ComfyUI** 画图，画完直接把图发到群里。
不联网、不调云端、不花一分钱。代价是一张要等 30~60 秒。

---

## 一、用之前要准备什么

| 需要 | 说明 |
|---|---|
| **QQ Agent** | 本技能是它的扩展 |
| **Comfy Desktop** | ComfyUI 的官方桌面版。**路径会自动发现，不用你填任何目录** |
| **至少一个画图模型** | 放进 ComfyUI 的模型目录，并且你在 ComfyUI 里能跑通它 |

**不需要**联网、**不需要** API Key、**不需要**注册任何服务。图片全程在你本机生成。

---

## 二、安装

1. 把技能装上（市场安装，或把压缩包解压到 `QQ Agent/resources/app/skills/comfy-draw/`）
2. 打开 QQ Agent 控制台的**「技能」页**，确认「本地绘图 (ComfyUI)」是**生效中**
3. 进**设置页** →「本地绘图 (ComfyUI)」，**只需要填一项：「模型文件名」**

填的就是 ComfyUI 里显示的那个完整名字（**含扩展名**）。

> **填错了不要紧。** 第一次画图时它会报错，并且**把 ComfyUI 里现有的模型名全部列出来**，
> 你照着上面列出的名字改就行。

---

## 三、怎么用

在群里正常说人话：

> 画一张猫娘
> 来张机箱壁纸
> 帮我画个赛博朋克风格的街道

**不用**特意说"用本地画图"——机器人自己判断该不该用。

画图期间它会先说一句「🎨 画着，稍等」（可以在设置里关掉）。

---

## 四、设置项说明

大多数项**留空就行**，下面只列你可能想动的：

| 设置项 | 什么时候要动 |
|---|---|
| **模型文件名** | **必填**。改模型时改这里 |
| 文本编码器 / 第二个文本编码器 / VAE / CLIP 类型 | 只有**拆分模型**才要填。单独一个文件的模型请全部留空 |
| 默认出图尺寸 | 留空 = 自动（单文件模型 1024×1024，拆分模型 812×1216）。想出竖图就填 `812x1216`，横图 `1216x812` |
| 采样步数 / CFG / 采样器 / 调度器 | 填 `0` 或 `auto` = 自动。不确定就别动 |
| 默认负向提示词 | 用来压制糊、水印、文字。可以按你的模型喜好改 |
| **画图时先打声招呼** | 关掉就没有「画着稍等」那句 |
| 单张出图超时 | 默认 5 分钟。**人多排队的群建议调大**（比如 600000 = 10 分钟） |
| 自动拉起 ComfyUI | 开着的话，ComfyUI 没运行时会由它后台启动（约 10~30 秒），你不用先开 Desktop |
| 保留旧图数量 | 默认 200。只清理**本技能生成的**图（文件名带 `qqagent` 前缀），你自己在 ComfyUI 里画的图不会被碰 |

## 五、已知问题与限制

**这一节是诚实清单，不是免责声明。遇到问题先看这里。**

### 1. 只在一种模型形态上实测过 ⚠️

本技能支持三种模型形态，但**只在「拆分模型 + 单编码器」上真正跑通验证过**：

| 模型形态 | 例子 | 状态 |
|---|---|---|
| 拆分模型 + 单编码器 | Anima、Qwen-Image | ✅ 实测通过 |
| 单文件模型（整合包） | SDXL / SD3 / FLUX 的整合版 | ⚠️ 代码支持，**未实测** |
| 拆分模型 + 双编码器 | FLUX / SD3 / SDXL 的拆分版 | ⚠️ 代码支持，**未实测** |

后两种的节点结构是照 ComfyUI 规范拼的，但没在真实模型上跑过。
**如果你用的是后两种并且失败了，请把报错发出来**——那是最有价值的反馈。

### 2. 人多的时候要排队

ComfyUI 一次只能画一张。群里几个人同时要画，后面的就得等——一张算 50 秒，三个人就是两分半。

本技能会提示「前面还有 N 张在画」，但**等太久会超时失败**（默认 5 分钟）。
群比较热闹的话，把「单张出图超时」调大。

### 3. 可能出现两个 ComfyUI 同时占显存

技能自动拉起 ComfyUI 之后，如果你**又手动打开 Comfy Desktop**，Desktop 会发现端口被占、
自己换一个端口再起一份。于是**两个实例各加载一份模型**，小显存显卡可能爆。

建议：**只用一种方式**——要么让它自动拉起，要么你自己一直开着 Desktop，别混用。

### 4. 功能缺口（还没做）

- **不支持 LoRA** —— 想画特定角色/画风时用不了，目前只能用基础模型
- **不支持图生图 / 参考图** —— 只有纯文字生成
- **不显示进度百分比** —— 只知道"在画"，不知道画到几成

### 5. 更新本技能后，需要重启 QQ Agent ⚠️

QQ Agent 的热重载**不会重新加载技能内部 `lib/` 目录下的模块**（ESM 模块缓存按路径缓存，
同一路径永远返回第一次加载的那份）。

表现很隐蔽：**技能看起来正常，但改动的代码没生效**。所以更新完请**重启一次 QQ Agent**。

### 6. 只在 Windows + ComfyUI v0.35.1 上验证过

用到的都是 ComfyUI 的核心节点和核心接口（跨版本一直很稳定），但**没有在多个版本上实测**。
macOS / Linux 的路径自动发现也**没有验证**过（Windows 的配置目录逻辑不同）。

## 六、想一起改进

发现 bug、或者后两种模型形态跑通了，都欢迎反馈。**带上这几样东西最有帮助**：

1. 报错原文（技能返回的那句话，或者 ComfyUI 的 `user/comfyui.log` 尾部）
2. 你的模型形态（单文件 / 拆分+单编码器 / 拆分+双编码器）
3. ComfyUI 版本（`(Invoke-RestMethod http://127.0.0.1:8188/system_stats).system.comfyui_version`）

代码结构：

```
comfy-draw/
├── skill.json            清单（所有可配置项在这里声明）
├── index.js              工具注册与主流程（提示、发送、参数校验）
└── lib/comfy-engine.js   ComfyUI 交互层（路径发现、端口探测、拉起、提交、取图）
```

改动 `lib/` 下的文件后记得**重启 QQ Agent**（见上面第 5 条）。
