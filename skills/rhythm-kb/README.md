# 音游知识库（rhythm-kb）· 使用与维护说明

给机器人加的能力：**有人问音游相关的问题时，先查这个库再回答；库里没有就照实说，不编。**

## 文件都在哪

| 内容 | 位置 | 能不能改 |
|---|---|---|
| 技能清单 | `skills\rhythm-kb\skill.json` | 需要改开关项才动，一般不用管 |
| 技能代码 | `skills\rhythm-kb\index.js` | 不用动 |
| 通用术语与机制 | `skills\rhythm-kb\kb\basics.json` | **可以直接用记事本改**，存盘即生效 |
| 各音游介绍 | `skills\rhythm-kb\kb\games.json` | 同上 |
| 新手与提升问答 | `skills\rhythm-kb\kb\faq.json` | 同上 |
| 社区词典词条 | `skills\rhythm-kb\kb\vsrg-terms.json` | 同上（整理自社区词典，见下） |
| Malody 官方资料 | `skills\rhythm-kb\kb\malody-official.json` | 同上（整理自 Malody 官方 wiki，见下） |
| 萌娘百科词条 | `skills\rhythm-kb\kb\moegirl.json` | 同上（整理自萌娘百科，见下） |
| 群友教的新条目 | `data\rhythm-kb\user-added.json` | 机器人自己写，也可以手改 |

> 上面路径都在 QQ Agent 的安装目录下：`D:\QQ agent\QQ Agent\resources\app\`。
> 完整路径示例：`D:\QQ agent\QQ Agent\resources\app\skills\rhythm-kb\kb\vsrg-terms.json`

## 机器人多了哪三个工具

| 工具 | 干什么 |
|---|---|
| 查音游知识 | 按关键词检索知识库，返回最相关的 1~5 条 |
| 音游知识目录 | 列出库里所有条目（按分类），用来告诉群友「库里有什么」 |
| 收录音游知识 | 有人明确说「记一下」时，把新知识写进 `user-added.json` |

这三个工具只在**有人问到音游**时才会被用到，不占平时的对话成本。

## 词条来源

- `basics.json` / `games.json` / `faq.json`：本地整理的通用内容（判定、连击、FC/AP、定数、潜力值、offset、主流音游介绍、新手问答）。
- `vsrg-terms.json`：整理自社区词典 **《下落式音游齐民要术 v0.74》**（作者：幽幽子的饲养员），
  面向 osu!mania / Malody / Etterna / Quaver 社区，覆盖键型（叠键、乱键、切换、面条、混合、秒杀、变速）、
  段位体系（4K/7K 各段）、判定区间与结算评级、外设键盘、练习谱与谱师、网站与工具、联机与社区礼仪等。
  每条都带 `"source"` 字段标明出处，检索时不影响匹配。
- 该词典里作者自己标注**存疑 / wip / 未定稿**的内容，词条 details 里都写明了这一点——
  机器人回答时会带上「资料标注为存疑」，不会把有争议的说法讲成定论。
- `malody-official.json`：整理自 **Malody 官方 wiki**（`m.mugzone.net`，官方运营团队维护），
  来源页：Malody 5.0 FAQ、Key Mode Stable Criteria(Draft)、Level Reference for charts、
  RM 模式计分特性介绍、Malody Metric。含官方判定窗口毫秒表、Judge/Mod 分数倍率、MM 分公式与等级系数、
  官方等级分段（Key 4K / Catch / Taiko）、谱面上架硬性要求（60 秒、OGG、192kbps 等）。
  数字全部照抄原文，并在 details 里附上英文原句便于对照。
- `moegirl.json`：整理自 **萌娘百科**（CC BY-NC-SA 3.0）的《音乐游戏》《音乐游戏/用语》《Malody》《Osu!》四个条目。
  以社区视角为主：通用黑话与各游戏专属术语（性、刁民、豆芽、科幻、开店/闭店、理接、天地押、黄彩比、UR、
  摘星、MM、TP…）、音游历史与共通要素、Malody/osu! 的机制概览。
  **注意与官方资料的区别**：萌娘百科是社区维基，同名术语在不同圈子含义可能不同，条目里都注明了所属圈子。
- 出处差异说明：**osu! 官方 wiki 从本机网络不可达**（全站登录墙，多语言页面 / 镜像 / GitHub 源仓库 / CDN /
  Wayback 快照都试过）。osu! 相关内容目前来自萌娘百科条目；若需要 osu! 官方口径，
  可把官方页面另存为 HTML 或 PDF 放到本机，再交给我整理入库。

## 怎么自己加一条知识

1. 用记事本打开任一份 `kb\*.json`。
2. 照着已有条目复制一段，改里面的内容。一条长这样：

```json
{
  "title": "条目标题",
  "aliases": ["别名一", "别名二"],
  "tags": ["标签"],
  "category": "分类名",
  "summary": "一句话说明，这段最常被用到",
  "details": "更详细的补充，可省略",
  "tips": ["小贴士一", "小贴士二"]
}
```

3. 保存。注意别删掉行尾的逗号规则（最后一条后面**不能有逗号**）。
4. 存盘后技能会热重载，不需要重启；想确认就回「技能」页看它还在不在。

> 只想省事的话：直接在群里对机器人说「记一下，XXX 是这样这样」，
> 它会用「收录音游知识」写进 `data\rhythm-kb\user-added.json`，不用你碰 JSON。

## 怎么看有没有生效

1. 打开 QQ Agent → **技能** 页签（不是插件页签），找到「音游知识库」。
2. 应该显示：已加载、已启用，并且能看到 3 个设置项（每次最多返回几条 / 没命中时列多少条 / 允许群友教新知识）。
3. 在群里问一句音游的问题，比如「定数是什么」「Phigros 的 RKS 怎么才能涨」「叠键和切有什么区别」，看它有没有按库里的内容回答。

## 内容口径

- 只写**稳定的**内容：玩法机制、术语、平台特征、经验。
- **不写**会随版本变化的数字：具体曲目的定数、曲目数量、价格、版本号。
  这是故意的——写死的旧数值比没有更糟，模型会当真。
- 库里查不到时，提示词要求机器人明确说「库里没有这条」，不允许凭印象编造。
- 键型类词条同一名词在不同社区含义可能不同，提示词要求以库里的条目为准。

## 出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 技能页显示「加载失败」 | `skill.json` 缺字段、`index.js` 有语法错 | 把页面上的错误原因原样发出来 |
| 技能页显示「不可用：音游知识库为空」 | `kb\` 目录下所有 json 都不见了或都解析失败 | 检查文件是否存在、JSON 是否合法 |
| 问了音游但机器人不查库 | 技能被关了，或工具被单独关掉 | 技能页确认开关；设置 → 工具与技能里确认「知识库」分类没被关 |
| 查不到某条 | 库里确实没有 | 自己加一条，或让机器人收录 |
| 想临时停用 | —— | 技能页关掉总开关即可，文件都保留 |
