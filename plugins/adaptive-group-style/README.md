# 群风格自适应学习（adaptive-group-style）

让机器人**自己观察每个群怎么说话**，把学到的说话习惯写进每次发言前的提示词，
使它的措辞跟着群友的实际风格走，而不是一套固定腔调复读。

- 类型：**确定性型插件**（放在 `plugins/`，靠 `hooks` + `promptSections` 工作）
- 位置：`plugins/adaptive-group-style/`
- 版本：**v1.1.0**（v1.0 白天统计 + v1.1 夜间整理官，见下）
- 依赖：白天部分**不联网、不调模型、零 token**；夜间整理（可选）会调用一次模型、联网对照热榜
- 开关：控制台「插件」页签 → 本条目 → 设置弹窗（配置写在 `config.skills['adaptive-group-style']`）

## 它做什么

| 时机 | 做什么 |
|---|---|
| 每次组装提示词前 | 到点（默认 30 分钟）就按本地聊天存档重新统计一次这个群的说话习惯 |
| 拼系统提示词时 | 把统计结果渲染成【群聊语言风格】段，插在系统提示词**末尾** |
| 本次输入发给模型前 | 再在用户消息末尾贴一小段紧凑版（最靠近发言位置，模型最当真） |
| 模型响应之后 | 记下机器人**真正发出去**的话，和群里的习惯比对，把偏差写进下一轮的提示词 |
| **每天休息时间的闲时（v1.1）** | **夜间整理官**：整理归档当天的聊天记录、复盘语气、联网学梗（见下节） |

学到的维度：句长（中位/上限/短句占比）、标点习惯（句末标点、逗号、波浪号、省略号）、
语气（笑声、叠字、emoji、括号补话）、分条节奏（一次连发几条）、口头禅/语气词白名单。

## v1.1 夜间整理官

每天在**人设卡里写的休息时间**（自动从人设文本解析，如「每日 24:00 到次日 8:00
不回复任何消息」；插件设置里也可显式覆盖），等宿主空闲超过 90 秒后，自动做四件事：

1. **整理归档**：取当天最活跃的前几个群（默认 3 个，每群需 ≥15 条群友消息），
   写出当日归档 `data/adaptive-group-style-archive/日期.json`。
2. **语气复盘**：统计机器人今天有没有"太冲"的话（贬低词、连续顶人），由模型对照
   群友的感觉给出明天的具体语气要求（如"被怼先接梗，不连续顶人两轮"）——
   方向是**进攻性更低、更像活人**。
3. **联网学梗**：把群里当天的高频词与热榜对照（优先用 hot-trend-tracker 插件缓存的
   `data/hot-trends.json`；过期时补抓 B站热搜/抖音热榜），群里认识但榜上没有的新词
   用搜索引擎查证（每晚上限 2 次）。命中的梗连同"怎么接才自然"写进提示词，第二天生效。
4. **写回档案**：复盘结果存进 `data/adaptive-group-style.json` 里对应群的 `night` 字段，
   与白天的统计互不覆盖，第二天起自动注入（36 小时保鲜——梗会过气）。

要点：

- **休息时间自动识别**：解析顺序 = 插件设置显式覆盖 → 人设卡文本（全局 → 自定义 → 内置）
  → 默认 00:00-08:00。启动日志会写明实际生效的窗口。
- **失败不硬撑**：模型全部失败时退回"确定性复盘"（纯统计的语气事实 + 固定调整建议），
  并在 30 分钟后重试（最多 2 次）；联网全部 try/catch，断了不挡整理。
- **隐私**：归档**只存提炼结果**（摘要/语气/梗/匹配/计数 + 机器人自己的样本），
  不保存群友的原始聊天——原始记录本来就在 `data/messages/`，归档的价值是"这一天的学习成果"。
- **不抢白天的话筒**：宿主一有消息处理（90 秒内忙过），夜间任务立刻让路；当日已整理
  就不再重复（按本地日期记在状态文件里）。
- 归档默认保留 30 天（`archiveKeepDays` 可调），过期自动清理。

## 数据来源

1. **本地聊天存档**（首选）：`data/messages/group_*.json`，通过宿主的 `ctx.store.recent()` 读
2. **记忆里已存的群友印象**（补充）：`ctx.memory.query(chatKey).memberImpression`
3. **机器人自己发过的话**：会话的 `session.sent`
4. **（v1.1）热榜与搜索**：`data/hot-trends.json` + B站/抖音热榜 + Bing 查词

刻意**没有**直读 SnowLuma 的 `messages.db` / 搜索记录库：那是另一个进程正在写的 SQLite，
有锁风险；而宿主内存里维护的 JSON 存档就是模型实际看到的同一份数据，走它才学得准。

## 状态文件

`<安装目录>/data/adaptive-group-style.json`（开发模式是 `<项目根>/data/`）。
删掉它就等于"忘掉学过的所有风格"（包括夜间复盘的语气/梗），下次发言重新学，
不会影响别的东西。

## 自检脚本（可选，与插件运行无关）

在 `resources/app` 目录下：

```bash
# 用真实聊天存档跑一遍统计，看"到底学到了什么"（只读、不写任何东西）
node plugins/adaptive-group-style/selftest.mjs

# 走宿主真实加载器跑完整流程，55 项断言（用系统临时目录，不碰真实 data/；
# 其中夜间整理部分用桩模型/桩网络，不花 token、不联网）
node plugins/adaptive-group-style/integration-test.mjs
```

`selftest.mjs` 可带一个存档文件路径作为参数，只看某个群。

## 已知边界（说清楚，不假装能做）

- **不读语义**：它只知道"群里平均几条字、爱不爱带句号"，看不懂"这句话是在开玩笑"。
  语气/情绪层面的适配仍然由模型自己完成，本插件只负责把"说法"校准到这个群。
- **样本不足就不学**：一个群少于 30 条群友消息（可调）时不给建议，并**保留上一次的档案**，
  不会因为群里刚好安静几小时就把学到的清空。
- **只影响"怎么说"**：人设、安全规则、工具用法完全不碰；片段 priority 固定 35（低于核心规则的 100）。
- **口头禅只给参考**：提示词里明确写了"别连着复读、也别硬塞"，避免学成新的复读机。
  不想让它提口头禅，可在设置里关掉「允许提示常用口头语」。
- **（v1.1）夜间整理是"闲时任务"**：只在休息时间且宿主空闲时跑；当天没活跃群就跳过；
  模型/网络失败会退化为确定性复盘，不会卡住也不会刷屏重试。
- **（v1.1）梗是"参考"不是"任务"**：提示词里写明"对上语境才用，一次最多一个，
  过了热度就放下"；防幻觉过滤保证只提示材料里真实出现过的词。
