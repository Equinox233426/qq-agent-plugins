# 内心生活（inner-life）

给 AI 角色一个**跨轮延续的内心**：情绪基调 + 还没想完、挂在心里的事。

---

## 它解决什么问题

这类宿主是**事件驱动**的：只有"对方发来消息"或"主动开口的机会到了"，角色才会被唤醒运行一次。

每次运行结束，它的思考就消散了 —— 下一次醒来，它只能从聊天记录里重新推理"我是谁、我刚才在想什么"，
注意力全被最新那条消息抓走，话题不会自己接回去。

结果就是：聊得再久，它看起来也是**每次重新开机**，没有连续的内在生活。

这个插件给它的是一根**接力棒**：

1. 每次运行结束前，它用 `mind_note` 记下"此刻的心绪"（情绪一句 + 还挂着的事）
2. 下一次运行开始时，插件把这段心绪**注入回提示词**（【你此刻的心绪】）
3. 它读到的是**自己上一次的状态**，于是能接着活 —— 而不是从零推理

> **边界说清楚**：它模拟不出"角色一直在想"。做的是"上一次的心绪写下来、下一次读回去"，
> 让连续内心**看起来存在**。这是这类宿主架构内能做到的上限。

---

## 工具

| 工具 | 作用 |
|---|---|
| `inner-life__mind_note` | 记下此刻的心绪：`mood`（情绪一句）+ `topics`（还挂着的事，最多 3 条） |
| `inner-life__mind_settle` | 想通了 / 结束了 → 放下某件心事（传关键词；不传 = 全部放下） |

---

## 装上就能用（默认自带使用说明）

**插件默认每一轮都会往提示词里注入一小段使用说明**，所以装完、启用、重启即可 —— **不用改任何人设**。

> 这同时修掉了一个"启动死锁"：如果说明只在"角色已经有心绪"时才注入，新装的用户就永远启动不起来 ——
> 模型不知道有这个工具 → 不会去记 → 永远没有心绪 → 永远不注入。

### 想自己写？可以（把 `injectGuide` 关掉，再用下面这段）

如果你更愿意把用法写进**角色的人设卡 / 系统提示**（更贴合自己的角色，也省一点 token），
就在插件设置里关掉**「自动注入使用说明」**，然后把下面这段加进人设。

⚠️ **两样至少要有一个**，否则模型不会去用这些工具。

### 建议人设片段（可直接照抄，按自己的称呼改）

```
【你的内心】
· 你有自己的内心：情绪、心事、没想完的话题，这些跨轮延续。
· 每次运行结束、finish 之前过一遍：有变化或者有新心事才用 mind_note 记
  （情绪一句、还挂着的事）；什么变化都没有就直接结束，别为了"记一次"把上一轮说过的事再说一遍。
· 下一轮开始你会读到自己记下的——先感受此刻真实的自己，还是这样才接着它，变了就更新。
· 想通的事、结束的话题，用 mind_settle 放下，别永远背着。
· 别把机制当话题：不说"我在记心绪""我的心绪刷新了"这类话——它只发生在你心里，说出去就假了。
```

> **重要**：如果你的人设有"每轮都要写点什么"的倾向，**一定要带上第 2 条那句"有变化才记"**。
> 实测中"每次都要记一次"这种指令会让角色把同一件事翻来覆去地记（换个说法就绕过判重）。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关（关掉后不再记录/注入，已存数据保留在磁盘上） |
| `topicTtlHours` | `12` | 心事保留多久后自动淡忘 |
| `moodTtlHours` | `24` | 情绪保留多久后回到平常心 |
| `maxTopics` | `3` | 同时挂着的心事上限（防膨胀） |

---

## 数据存在哪

`data/inner-life/<会话键>.json`（每个会话一份），与聊天记录、与宿主的"印象记忆"**完全独立**，互不挤占。

想清空某个会话的心绪：直接删这个文件即可。

## 给想改代码的人

- `index.js` —— 两个工具 + 每轮注入（`promptSections`）
- `lib/store.js` —— **零依赖纯模块**，root 可注入，所以能离线跑断言
- 防 bug 原则：IO 全 try/catch、原子写入（tmp + rename）、TTL + 容量双保险、失败只降级不抛错
- 心事判重是**语义近似**而不是逐字比对：同一件事换个说法（多几个字少几个字）只算一件。
  规则见 `lib/store.js` 的 `isSameTopic`：归一化（去空白、去标点）后相等，或一方包含另一方且
  短句 ≥6 字、占长句 ≥50%。命中时只刷新"最近触碰时间"，不新增第二条
- 过期用的是**最近一次触碰**时间（`touchedAt`）而不是创建时间：她还在惦记的事不会在她还想着的时候淡忘。
  注意"每轮注入"**不会**续期 —— 只有它主动重新记一次才算"还在惦记"

## 更新说明

### 1.0.1
- **挂心事只挂真没想完的**：随口起的玩笑、玩过的梗、打趣过的待办**不算心事、会被排除在外** ——
  否则一个梗会被反复提起（它每轮都会被注入回提示词，她就会一直惦记），反而变假。
- 建议心绪里**至少留一件是她自己的**（她自己的烦恼、想不通的事），而不是全是"关于他的事"。
