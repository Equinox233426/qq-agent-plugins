# heartbeat —— 心跳

给角色一颗**会跳的心**：被夸、被撩、被盯着看、被说中的时候，心跳会快、会脸红；
之后随时间自然平复。

它注入的是**身体感觉**，不是分数条。目的是影响语气——句子变短、嘴硬、岔开话题、
答非所问——而不是让它播报"我心跳 120"。

---

## 和已有插件的分工

| 插件 | 管什么 | 时间尺度 |
|---|---|---|
| `inner-life` | 情绪基调 + 挂心事 | 小时 |
| `life-memory` | 仿真实生活、每日规划 | 天 |
| `affinity` | 群友好感度（按人） | 长期 |
| **`heartbeat`** | **这一场对话里的生理反应** | **秒~分钟** |

上面三个都是慢变量。心跳补的是"被那句夸完之后，接下来三句话该怎么说"。

---

## 怎么用

装上即可用。每轮提示词里会带一小段使用说明，模型知道有 `heartbeat__heart_beat` 这个工具。

被戳中时它自己记：

```
heart_beat({ flutter: 2, shy: 1, why: "被夸好看" })
```

`flutter` = 心动，`shy` = 害羞，都是 **0~3 的绝对档位**（不是加多少）。
传 0/0 表示主动平复。

下一轮提示词里就会出现：

```
【你此刻的身体反应（别报数字、别直接说出来，让它影响语气就行）】
· 心跳快得压不住（约 106），说话容易卡壳
· 有点不好意思，视线想躲一下
· （因为：被夸好看）
```

---

## 衰减

指数衰减，默认**半衰期 8 分钟**：

```
刚记完      106 下/分   有身体反应
过 8 分钟    87 下/分   有
过 16 分钟   77 下/分   有
过 60 分钟      -       不注入
```

一场对话内还有余温，隔一顿饭就平了。半衰期可在设置里改（1~180 分钟）。

**实现上不用定时器**：只存「上次计算时刻 + 当时的数值」，读的时候按经过时间算。
好处是永远准确、进程重启也不丢、不用管 `start/stop/dispose`。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 关掉后不记录也不注入，磁盘上的状态保留 |
| `injectGuide` | true | 每轮带使用说明。关掉省 token，但要自己把人设指令写进角色卡 |
| `halfLifeMin` | 8 | 平复半衰期（分钟） |
| `maxLevel` | 3 | 心动/害羞的最大档位 |
| `quietWhenCalm` | true | 平静时只带说明、不带身体反应 |

**关掉 `injectGuide` 的话**，把这段写进角色卡：

```
被夸、被撩、被盯着看、被说中、被突然靠近的时候，你的心跳会快、会脸红。
这种时候用 heartbeat__heart_beat 记一下（flutter 心动 0~3、shy 害羞 0~3，是"现在有多强"不是"加多少"）。
只在真被戳中时用；被戳中过一次之后不用每轮再记，它会自己慢慢平复。
感觉是给你自己的，不要说出口——不说"我心跳 120"，也不提这个工具，让它影响语气就行。
```

## 文件

- 状态存 `data/heartbeat/<chatKey>.json`
- 每个会话一份，原子写入（tmp + rename）
- 所有 IO 都 try/catch，失败只降级不抛错

## 已知

- `plugins/heartbeat` 会有一条加载警告「没有提供能力或钩子」。那是加载器的启发式判断
  （只看 `providers` / `hooks`，不看 `registerTool` / `promptSections`），**不影响功能**。
  `inner-life` 也有同样的警告且工作正常。
- 工具的两个参数在 schema 里允许到 5（因为 `maxLevel` 可配），但实际会被 `maxLevel` 夹住。
