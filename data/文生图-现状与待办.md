## 一个未验证的点（限制解除后请留意）

`image-generate` 技能固定会发 `n: 1` 这个字段：

```js
// skills/image-generate/index.js:307
body.n = count;
```

但**火山方舟的图片接口文档里没有 `n` 参数**（它是 OpenAI 的写法，火山一次只生成一张）。

现在的 429 是在「模型访问」这一层就被拦住的，**还没走到参数校验**，所以不知道火山会不会因为多出来的 `n` 报错。

- 如果解除限制后能正常出图 → 火山忽略了它，不用管
- 如果报参数错误 → 需要改 `buildBody`，把 `n` 去掉

## 网络说明（火山是国内直连，不绕代理）

`启动QQ机器人.bat` 里设了代理，但火山已加进白名单：

```bat
set HTTPS_PROXY=http://127.0.0.1:7890
set NO_PROXY=127.0.0.1,localhost,::1,api.deepseek.com,open.bigmodel.cn,api.bilibili.com,ark.cn-beijing.volces.com,volcengine.com,snowluma
```

**为什么需要代理**：这台机器的 iKuuuVPN 是 TUN 模式，它把 `api.openai.com` 路由到死路；
Clash 的 7890 是通的。而火山/B站/DeepSeek/智谱都在 `NO_PROXY` 里走直连。

**别加 `NODE_USE_ENV_PROXY=1`** —— Electron 35 的 Node 22 自带认 `HTTPS_PROXY`，加上反而 ECONNRESET（三组对照实测）。
